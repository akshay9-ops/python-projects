## Running a project

Each folder is self-contained. From inside a day's folder:

```
pip install -r requirements.txt   # if present
python main.py
```

Some projects (e.g. Hirst Painting) use turtle or other GUI libraries and need to be run locally rather than in a browser sandbox.
